# Coaching restart pilot

A public download, shared at its owner's explicit request.

The organizer opens Codex and signs in. The participant only talks about the
project; the agent prepares the tools and existing materials automatically.

Copy FIRST-PROMPT.txt into Codex. It reads START-HERE.md, detects the actual
computer and selects the current package from distribution.json.

Supported candidates: macOS14+ Apple Silicon and native Windows x64. The selected
live test is on Apple Silicon. See QUALIFICATION.md for what was actually tested.
ChatGPT Work and Intel Mac are not qualified by this delivery.

- [Copyable first prompt](FIRST-PROMPT.txt)
- [Agent startup](START-HERE.md)
- [Exact platform downloads and hashes](distribution.json)
- [Current release](https://github.com/codynoskov/meaningfall-coaching-pilot/releases/tag/coaching-20261102-r3)

The packages include Python, portable Git, local intake model inputs and the128
selected Coaching originals. First setup needs internet and several GB of free
space. No manual Git/Python/GitHub installation or GitHub login is needed.

The owner explicitly requested open unauthenticated download of these Coaching
files. This is not a blanket reuse license for project/personal material and
permits no new website publication or account operation. Historical private/local
labels in preparation reports retain their earlier scope; the private Meaningfall
Lab repository is not opened. Software retains its included licenses.
