# Coaching onboarding pilot

Public download for the owner's Coaching restart test in native Codex on Windows x64.

- [Download the complete package](https://github.com/codynoskov/meaningfall-coaching-pilot/releases/download/coaching-windows-20261102-r2/Coaching-Pilot-Windows-20261102-r2.zip)
- [Agent startup instructions](START-HERE.md)
- [Copyable first prompt](FIRST-PROMPT.txt)

The organizer installs/opens a Codex-capable desktop app and signs in with the
participant's own account. The participant then communicates in ordinary language.
The package includes local Python, portable Git and existing Coaching materials;
no manual Git/Python/GitHub CLI setup or GitHub sign-in is required to download it.
First-time dependency downloads require internet and several GB of free disk.

This public archive was shared at the owner's explicit request. It contains the
supplied Coaching source documents, images and other project materials. The private
Meaningfall Lab repository is not made public. Historical local-only/private labels
inside preparation reports describe the earlier preparation stage or the intended
local working project; they are not access controls on this public download.

Actual Windows setup and the human onboarding have not yet been observed. This is
a supervised pilot candidate. Only the ordinary Codex host route is prepared;
ChatGPT Work startup and separate SDK subprocess inference are not qualified by
this package. Publication of the download does not authorize publishing the generated
website, connecting accounts, importing credentials or treating drafts as accepted.
